# UI-концепции «ПотребКонсульт»

**Инструмент:** v0.dev (резервно — Galileo AI / Uizard).
**Экран для генерации:** главный экран чата с ответом ассистента — это ядро продукта, на нём лучше всего видны различия концепций.

Для каждой концепции ниже: промпт для Text-to-UI инструмента, ключевые особенности, плюсы и минусы. Скриншоты сохраняются в эту же папку под именами `concept_1.png`, `concept_2.png`, `concept_3.png` (и мобильные версии `*_mobile.png`).

> После генерации сверьте описание с тем, что фактически выдал инструмент, и поправьте детали, если результат отличается.

## Концепция 1. «Мессенджер» — минималистичный стиль

**Промпт для v0:**
```
Design a minimalist web chat app called "ПотребКонсульт" — an AI assistant for consumer rights in Russia.
All UI text in Russian. Light theme, lots of white space, one accent color (calm blue), Inter font.
Layout: single centered column (max 720px) like a messenger. Top bar: logo, small disclaimer
"Справочная информация, не замена юриста". Chat: user message bubble on the right
("Купил наушники, через неделю сломались, магазин отказывается менять"), assistant answer on the left
with short paragraphs and small gray source chips under it ("ст. 18 ЗоЗПП", "ст. 19 ЗоЗПП").
Under the answer: thumbs up/down icons and a text button "Составить претензию".
Bottom: input field "Опишите вашу ситуацию…" with send button. Responsive, mobile-first. React + Tailwind.
```

**Ключевые особенности:**
- одна колонка, всё внимание на диалоге;
- источники — компактные серые чипы под ответом;
- действия (оценка, претензия) — мелкие и ненавязчивые.

**Плюсы:** знакомый всем паттерн мессенджера, минимум элементов, идеально адаптируется под телефон, быстро реализуется.
**Минусы:** источники легко не заметить, хотя это главное отличие продукта; новому пользователю непонятно, о чём можно спрашивать (пустой экран).

## Концепция 2. «Помощник» — яркий и дружелюбный стиль

**Промпт для v0:**
```
Design a bright, friendly web app "ПотребКонсульт" — an AI helper for consumer rights in Russia.
All UI text in Russian. Warm palette (coral and soft yellow accents on light background), rounded cards,
large readable font (18px base) suitable for elderly users, simple line icons.
Start screen: greeting "Здравствуйте! Расскажите, что случилось с покупкой" and a grid of 6 large topic cards
with icons: "Сломался товар", "Хочу вернуть товар", "Задержали доставку", "Не вернули деньги",
"Некачественная услуга", "Покупка в интернете". Below — big input field with microphone icon.
Chat view: answer in a large rounded card with bold key points list and a highlighted yellow block
"Что делать дальше: 1) … 2) … 3) …", sources as colored badges. Big primary button "Составить претензию".
Responsive. React + Tailwind.
```

**Ключевые особенности:**
- стартовый экран с карточками типовых ситуаций;
- крупный шрифт и крупные элементы управления;
- ответ структурирован: ключевые пункты + блок «Что делать дальше»;
- заметная кнопка генерации претензии.

**Плюсы:** понятно с первого взгляда, о чём спрашивать; удобно пожилым пользователям; хорошо подчёркивает практическую пользу (план действий, претензия).
**Минусы:** «игривый» стиль может снижать доверие к юридической информации; карточки занимают много места на мобильном; источники по-прежнему вторичны.

## Концепция 3. «Справочная» — корпоративный стиль с панелью источников

**Промпт для v0:**
```
Design a professional, trustworthy web app "ПотребКонсульт" — an AI legal reference assistant for consumer
rights in Russia. All UI text in Russian. Corporate style: navy and white, subtle gray borders,
serif headings + sans-serif body.
Desktop layout with two panels: left (60%) — chat with the assistant; right (40%) — "Источники" panel
showing cards of law articles cited in the selected answer: article title "Статья 18. Права потребителя
при обнаружении в товаре недостатков", document name "Закон РФ «О защите прав потребителей»",
a quote with highlighted relevant sentence, link "Открыть полный текст".
In the answer, citations are inline numbered markers [1], [2] linked to the source cards.
Top bar: logo, "База актуальна на 01.10.2026", disclaimer. Under each answer: "Полезно / Неполезно",
"Составить претензию". On mobile the sources panel becomes a bottom sheet opened by "Источники (2)".
React + Tailwind.
```

**Ключевые особенности:**
- две панели: чат и источники;
- сноски [1], [2] в тексте ответа связаны с карточками статей;
- в карточке — цитата с подсветкой релевантного фрагмента;
- дата актуальности базы в шапке;
- на мобильном панель источников превращается в выезжающую снизу шторку.

**Плюсы:** главная ценность продукта — проверяемость ответа — видна сразу; вызывает доверие; удобно и обычному пользователю, и консультанту; хорошо демонстрирует RAG на защите магистерской.
**Минусы:** сложнее в реализации (связь сносок и карточек, шторка на мобильном); на маленьких экранах источники скрыты за дополнительным нажатием; пустой стартовый экран так же неинформативен, как в концепции 1.

## Выбор: концепция 3 с заимствованием из концепции 2

По сумме баллов концепции 2 и 3 равны, но выбрана **концепция 3**, потому что она лучше всего показывает ключевое отличие продукта от универсальных чат-ботов — каждый ответ можно проверить по тексту закона. Для юридической темы доверие важнее «дружелюбности», а для магистерской работы наглядная связь «ответ → источник» напрямую демонстрирует работу RAG.

Её слабое место — неинформативный стартовый экран — закрывается заимствованием из концепции 2:
- на стартовом экране — карточки типовых ситуаций («Сломался товар», «Хочу вернуть товар» и т.д.);
- в ответе — выделенный блок «Что делать дальше»;
- базовый размер шрифта 17–18px и контрастность не ниже WCAG AA.

Концепция 1 отклонена: при простоте реализации она прячет источники, то есть главную ценность продукта.
